## How updates work

My tools can **create** a Google Doc but not edit one in place, so:

- The **HTML source in this folder is the living master** — always current, versioned here.
- The Google Doc is regenerated from it at milestones. A regenerated Doc gets a **new link**,
  which I'll share each time (and update above).

If you'd rather keep one stable Doc link, just edit the Doc yourself between milestones and
I'll fold your edits back into the source.
